Diagrams

Import model

Creates a new model from an ArchiMate 3 Open Exchange file (POST /models/import). The file is validated by the API. A file of a model that is already there is refused, unless you replace that model or import the file as a separate model (a copy).

Also an Archi file (.archimate): the API converts it with Archi. For a new version of a model, exported again from its source. You first see what would change, and confirm. The model keeps its number; its content is replaced by the file's in one step, and a file that fails leaves it as it was. Diagram links and moved elements of that model may no longer fit; baskets are kept.

New model

Linked file

A linked model is updated from a file that the API reads on the server, an Archi file (.archimate) or an exchange file (.xml, API 3.1.0), by hand or every few minutes, and cannot be changed otherwise. Only files in the folders the server allows can be linked.
